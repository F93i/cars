لوحة تحكم المعرض

اربط اللوحة بمستودع GitHub الخاص بموقعك لتنشر التعديلات مباشرة.

اتركه فارغاً لاستخدام الفرع الافتراضي.

إذا كان GitHub API محجوباً عندك، استخدم هذا الوضع: تعدّل هنا ثم تنزّل ملف ZIP وترفعه بنفسك من موقع GitHub.

كيف أنشئ رمز الوصول؟
  1. ادخل GitHub ← Settings ← Developer settings.
  2. Personal access tokens ← Fine-grained tokens ← Generate new token.
  3. في Repository access اختر Only select repositories ثم اختر مستودع الموقع فقط.
  4. في Permissions ← Repository permissions اجعل Contents على Read and write.
  5. اضغط Generate token وانسخ الرمز والصقه هنا.

الرمز يُحفظ في متصفحك فقط ولا يُرسل إلا إلى GitHub. استخدم رمزاً مقتصراً على هذا المستودع، ولا تفتح اللوحة من جهاز مشترك. زر «خروج» يمسح الرمز من المتصفح.
